소셜 데이터 수집

YouTube의 영상·채널 지표와 댓글, Instagram의 공개 게시물·댓글을 수집해 Excel과 HTML 보고서로 정리합니다. YouTube API 키나 Instagram 로그인이 필요한 경우가 있습니다.

파일 변환·압축

이미지 형식·크기·용량을 조절하고 자르기 미리보기로 확인합니다. 지원 문서를 변환하거나 파일을 압축·분할합니다. 일부 문서 변환 도구는 별도 연결이 필요합니다.

대용량 파일 링크

파일을 모아 서비스와 공유 범위를 확인한 뒤 네이버 또는 Google Drive에 업로드합니다. 진행 상태를 보고 만든 링크를 다시 찾을 수 있습니다.

저장 공간 분석

선택한 드라이브·폴더에서 공간을 차지하는 파일을 찾고, 크기와 형식별로 살펴봅니다. 분석 기록은 PC에서 직접 관리합니다.

Google Drive BETA · 심사 중

본인의 Google 계정으로 권한을 허용한 뒤, 선택한 파일을 본인의 Drive에 올리고 공유 링크를 만듭니다. 워크킷이 만든 파일 또는 사용자 선택으로 허용한 파일에 대한 drive.file 권한을 사용합니다.

Google 로그인은 기본 브라우저에서 진행하며 워크킷에 Google 비밀번호를 입력하지 않습니다. 연결 토큰과 작업 기록은 사용자 PC에 보관합니다. 업로드는 PC에서 Google로 직접 전송하며 운영자의 서버를 거치지 않습니다.

Google Drive는 BETA · 심사 중입니다. 일부 계정은 연결이 제한될 수 있습니다. 연결할 수 없다면 네이버 메일을 이용해 주세요. Google 승인 완료를 의미하지 않습니다.
