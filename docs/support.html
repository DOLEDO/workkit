설치·백신 차단

설치나 실행이 막히면 차단 제보에 백신 제품명·탐지명·파일명을 남겨 주세요. 화면의 개인 정보는 가려 주세요.

현재 1.0.2 설치 파일과 앱은 미서명입니다. 차단만으로 오탐 여부를 확정할 수 없습니다. 백신 끄기나 폴더 전체 예외 등록을 권하지 않습니다. V3 오탐 분석 안내

접수 순서

  1. 위에서 문의 종류를 고릅니다.
  2. 사용 기능과 문제 상황을 적습니다. 오류에는 버전·Windows·재현 순서를 함께 적어 주세요.
  3. 등록한 글에서 답변을 확인합니다. 추가 정보도 같은 글의 댓글로 남겨 주세요.

앱에서는 설정 → 도움말·문의로 접수할 수 있습니다. ‘환경 정보 복사’로 버전·Windows 정보를 복사할 수 있습니다.

내 문의 보기 · 전체 접수 현황 · 사용법

공개 게시판입니다. API 키·비밀번호·토큰·개인 파일·다운로드 링크는 올리지 마세요. 화면의 계정명·회사명·파일 경로도 가려 주세요.

순차적으로 확인하며, 일정한 응답 시간을 보장하지 않습니다.
