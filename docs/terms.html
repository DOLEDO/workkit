이용약관

워크킷 WorkKit · 운영자 DOLEDO · 적용일 2026년 11월 12일

1. 제공하는 기능

워크킷은 Windows에서 파일 변환·압축, 저장 공간 분석, 대용량 링크 생성 및 소셜 데이터 수집을 돕는 독립 데스크톱 도구입니다. 기능별 지원 범위는 배포 버전과 사용법에 표시합니다. 현재 공개 배포 준비 중이며 일부 연결과 수집 기능은 외부 서비스의 허용 범위와 상태에 따라 달라집니다.

2. 사용자가 확인할 사항

사용자는 자신이 처리·업로드·수집할 권한이 있는 자료만 선택하고 관련 법령, 회사 정책 및 외부 서비스 약관을 준수해야 합니다. 접근 제한·로그인·보안 확인을 우회하는 용도로 사용하지 마세요. 업로드 서비스와 공개 공유 범위를 실행 전에 확인하세요.

3. 결과와 외부 서비스

파일 변환 품질, 수집 가능 범위·정확도, 링크 유효기간 및 업로드 제한은 원본 자료와 외부 서비스 상태에 영향을 받습니다. 최종 업무에 사용하기 전에 결과를 확인하고 중요한 원본을 별도로 보관하세요. 워크킷은 네이버·Google·Meta의 공식 제품이나 제휴 제품이 아닙니다.

4. 요금과 배포

공개한 워크킷 버전은 별도 앱 사용료 없이 제공합니다. Google Drive 저장 공간, API 및 외부 서비스의 이용 요금이나 사용량 제한은 각 계정과 서비스 정책을 따릅니다. 설치 파일과 변경 안내는 이 저장소의 Releases에서 배포합니다. 소스 코드 전체 공개를 의미하지 않습니다. 포함된 외부 구성요소와 글꼴의 권리는 각 라이선스를 따르며 설치 파일의 고지를 함께 확인하세요.

5. 업데이트와 이용 종료

업데이트로 기능이나 요구 환경이 바뀔 수 있으며 변경 사항을 배포 안내에 표시합니다. 사용자는 언제든 연결을 해제하고 앱을 제거할 수 있습니다. 제거만으로 사용자 결과·로컬 기록·서비스에 업로드한 파일이 자동 삭제되지는 않습니다. 삭제 방법은 개인정보처리방침과 사용법을 참고하세요.

6. 문의와 변경

운영자는 DOLEDO이며 GitHub Issues로 오류·기능 문의를 받습니다. 공개 게시판에 계정 정보나 민감한 자료를 올리지 마세요. 이 약관을 변경하면 적용일과 변경 내용을 갱신합니다.
