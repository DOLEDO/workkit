개인정보처리방침

워크킷 WorkKit · 운영자 DOLEDO · 적용일 2026년 11월 12일

이 방침은 Windows용 워크킷 앱과 이 소개 사이트에 적용됩니다. 워크킷은 별도의 회원가입이나 운영자 업로드 서버 없이 사용자 PC에서 실행합니다.

1. 처리하는 정보와 목적

  • 파일 변환·압축: 사용자가 선택한 파일의 내용·경로·형식·크기를 읽고 결과 파일을 만듭니다. 이 작업 자체로 원본 파일을 운영자에게 전송하지 않습니다.
  • 저장 공간 분석: 사용자가 선택한 위치의 파일·폴더 경로, 크기, 날짜 등 메타데이터를 읽어 PC에 분석 기록을 만듭니다.
  • 소셜 수집: 사용자가 지정한 공개 계정·게시물·댓글·지표, 선택한 화면 캡처와 수집 상태를 PC에 저장하고 사용자가 요청한 보고서로 내보냅니다. YouTube API 키와 Instagram 로그인 세션은 해당 기능의 연결에 사용합니다.
  • Google Drive: OAuth 접근·갱신 토큰, 연결 계정의 표시 정보, 선택한 업로드 파일의 내용·이름·크기, 업로드 진행 정보와 생성한 파일 식별자·공유 링크를 업로드·권한 설정·작업 재개·링크 기록을 위해 처리합니다.
  • 네이버: 앱 전용 로그인 세션과 선택 파일, 생성한 다운로드 링크·처리 상태를 대용량 링크 생성에 사용합니다.

2. Google 사용자 데이터의 사용

요청 범위는 https://www.googleapis.com/auth/drive.file입니다. 앱이 생성한 파일 또는 사용자가 앱에서 사용하도록 허용한 파일에 대해 업로드, 파일 정보 확인, 선택한 공유 권한 설정과 링크 생성에 사용합니다. Drive 전체를 탐색하는 권한을 요청하지 않습니다.

Google 사용자 데이터는 사용자에게 제공하는 위 기능과 그 유지·보안 목적에만 사용합니다. 광고, 데이터 판매, 신용도 판단 또는 범용 AI·머신러닝 모델의 학습에 사용하지 않습니다. 워크킷의 Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 Google API Services User Data Policy 및 Limited Use 요구사항을 준수합니다.

3. 외부 전송과 공유

사용자가 업로드를 확인하면 파일과 요청에 필요한 정보가 PC에서 선택한 서비스인 Google 또는 네이버로 직접 전송됩니다. 소셜 수집 요청은 해당 서비스에 접속합니다. 서비스 제공자의 처리는 각 서비스의 약관과 개인정보처리방침에 따릅니다. 운영자의 자체 서버로 파일·키·토큰을 수집하거나 광고·분석 업체에 제공하지 않습니다.

Google Drive의 ‘링크가 있는 모든 사용자’ 공유를 선택하면 링크를 받은 사람이 파일에 접근할 수 있습니다. ‘제한됨’은 Drive의 허용된 사용자만 접근할 수 있습니다. 네이버 링크도 전달받은 사람이 다운로드할 수 있으므로 민감한 링크를 공개하지 마세요.

4. 보관과 보호

결과 파일은 사용자가 지정한 위치에, 설정·인증 상태·수집 및 분석 기록은 사용자 PC의 워크킷 데이터 경로에 보관합니다. Google 토큰은 Windows 현재 사용자 기준으로 암호화해 저장합니다. 브라우저 로그인 세션은 각 연결용 브라우저 프로필에서 관리합니다. 모든 내보낸 파일이나 기록이 암호화되는 것은 아닙니다.

설정과 결과·기록은 사용자가 삭제할 때까지 남을 수 있습니다. 앱 제거·업데이트로 사용자 결과와 기록을 자동 삭제하지 않습니다. 네이버 로그인 유지 기간, 서비스 토큰의 유효성 및 원격 파일 보관 기간은 앱 선택과 해당 서비스 정책의 영향을 받습니다.

5. 연결 해제와 삭제

앱의 설정 → 계정·API 연결에서 연결을 해제할 수 있습니다. Google 연결 해제는 로컬 토큰을 삭제하고 Google 권한 철회를 요청합니다. 네트워크 등의 이유로 철회하지 못하면 Google 계정의 연결 관리에서 직접 접근 권한을 삭제하세요.

연결 해제나 로컬 링크 기록 삭제는 Drive·네이버에 이미 업로드한 파일을 삭제하지 않습니다. 원격 파일·공유 권한은 해당 서비스에서 관리하세요. 수집·분석 기록은 앱의 기록 관리에서 삭제하고, 내보낸 파일은 저장 폴더에서 직접 삭제할 수 있습니다. 앱을 닫은 뒤 Windows 사용자 로컬 앱 데이터의 FileTools 폴더를 직접 관리할 수도 있습니다.

6. 사이트 방문과 문의

이 사이트는 GitHub Pages로 제공하며 자체 광고·방문 분석 스크립트를 넣지 않습니다. GitHub는 보안 목적으로 방문자의 IP 주소 등을 처리할 수 있습니다. GitHub 개인정보처리방침을 확인하세요.

운영자: DOLEDO. 개인정보 관련 문의와 삭제 요청의 접수 경로는 GitHub Issues입니다. 공개 게시판이므로 비밀번호·토큰·개인 파일·비공개 링크를 게시하지 마세요. 운영자는 사용자의 로컬 파일이나 서비스 계정에 직접 접근할 수 없습니다.

7. 변경 안내

방침이 바뀌면 이 페이지의 적용일과 변경 내용을 갱신합니다. 새로운 처리 목적이나 권한이 필요한 경우 앱 안내와 권한 요청에 반영합니다.
