설치·백신 안내

설치 전에 공식 다운로드 주소와 파일 이름을 확인해 주세요.

워크킷 1.1.0 설치 파일은 코드 서명되지 않았습니다. Windows 또는 백신이 확인 메시지를 표시하거나 실행을 차단할 수 있습니다. 경고나 차단만으로 안전 여부를 판단할 수는 없습니다.

1. 공식 파일 확인

워크킷 1.1.0 공식 배포 페이지에서 WorkKit-1.1.0-Setup-x64.exe를 받으세요. 배포 페이지의 SHA256SUMS 파일과 다운로드한 파일의 SHA-256을 비교하면 다운로드 과정에서 파일이 달라졌는지 확인할 수 있습니다.

2. 기존 버전을 사용하고 있다면

1.0.2에서 처음 전환할 때는 작업을 저장하고 워크킷을 종료한 뒤, Windows 설정의 설치된 앱에서 이전 워크킷을 제거하고 1.1.0 설치 파일을 실행하세요. 개인 설정·기록·결과 파일은 유지됩니다. 처음 사용하는 사람은 설치 파일만 실행하면 됩니다.

3. 실행이 차단되었다면

백신 제품명과 탐지명, 차단된 파일명을 확인해 차단 제보로 알려 주세요. V3의 경우 안랩 오탐 분석 안내도 확인할 수 있습니다. 회사 PC는 담당 보안팀의 안내를 따르세요.

백신을 끄거나 폴더 전체를 검사 예외로 등록하지 마세요. 경고 내용을 확인할 수 없다면 설치를 중단하고 문의해 주세요. 제보할 때 계정 정보·파일 경로·개인정보는 가려 주세요.

4. 업데이트

새 설치 방식으로 전환한 뒤에는 앱에서 업데이트를 다운로드하고 직접 다시 시작해 적용합니다. 작은 변경은 가능한 경우 부분 다운로드하며, 상태에 따라 전체 다운로드가 필요할 수 있습니다.
