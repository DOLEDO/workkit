워크킷 시작하기

설치 후 필요한 도구를 골라 사용하세요.

  1. 설치

    Releases에 설치 파일이 게시되면 Windows x64용 Setup EXE를 내려받아 실행합니다. .NET과 수집용 Chromium이 포함되어 Python 설치는 필요하지 않습니다. 네이버 연결에 필요한 WebView2가 없으면 앱의 공식 안내를 확인하세요. 회사 PC에서는 설치·실행 정책을 먼저 확인하세요.

  2. 결과 저장 위치

    새 사용자는 Windows의 현재 사용자 다운로드 폴더 아래 ‘워크킷’을 기본으로 사용합니다. 설정 → 저장 위치에서 지정 폴더 또는 원본 옆 ‘변환 결과’를 선택합니다. 기존 사용자 설정은 유지됩니다. 소셜 수집은 내보내기 때 저장 창에서 최종 위치를 선택합니다.

  3. 우클릭으로 시작

    설치 때 우클릭 메뉴를 선택하면 ‘워크킷으로 열기’와 ‘메일 링크 만들기 → 네이버 / Google Drive’를 사용할 수 있습니다. Windows 11에서는 ‘더 많은 옵션 표시’ 안에 보일 수 있습니다.

  4. Google Drive 링크

    파일 추가 → 화면 하단에서 Google Drive·공유 범위 선택 → Google로 만들기 → 기본 브라우저에서 Google 로그인·권한 허용 → 업로드 진행 → 링크 복사 순서입니다. 공개 게시 전에는 테스트 계정 제한이 있을 수 있습니다. 파일은 자신의 Drive에 저장됩니다.

  5. 네이버 링크

    파일을 모은 뒤 화면 하단에서 네이버 메일을 선택하고 네이버로 만들기를 누릅니다. 필요한 경우 전용 창에서 직접 로그인하고 이후 첨부·내게쓰기·링크 추출을 자동 처리합니다. 연결 상태나 네이버 화면 변경으로 실패할 수 있으므로 안내와 실제 결과를 확인하세요.

  6. 기록과 연결 관리

    만든 링크와 소셜 수집 기록은 각 도구에서 다시 확인합니다. 디스크 분석 기록의 보관 용량은 설정 → 기록·저장공간에서 관리합니다. 연결은 설정 → 계정·API 연결에서 해제할 수 있습니다.

  7. 업데이트

    설정 → 우클릭 메뉴·앱 정보에서 새 버전을 확인합니다. 자동 확인은 6시간 간격으로 제한하며 설정에서 끌 수 있습니다. 새 버전 알림의 ‘패치 노트 보기’를 누르면 해당 버전의 변경 사항과 설치 파일이 있는 GitHub Releases 페이지를 엽니다. 설치는 직접 진행합니다.

문제가 있으면 오류 제보에 버전·기능·오류 문구를 남겨 주세요. 토큰·비밀번호·개인 파일·다운로드 링크는 공개하지 마세요.
